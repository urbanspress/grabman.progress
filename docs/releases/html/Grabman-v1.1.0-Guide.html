Grabman v1.1.0 — Plain-English Walkthrough Guide

Project Scaffolder, Compatibility Doctor, Site DNA Validator & Deterministic grabman.lock Solver (Step 5 • Layer 1)

Release Tier: MINOR 1.1.0 — Interactive Scaffolder & Dependency Health • Runtime: Pure Go Stdlib Static Binary (CGO_ENABLED=0) • Ecosystem Baseline: GRAB v1.1.0 + 6-Layer Contract Matrix

What Grabman Does in Plain English: Before you deploy a GRAB application, CMS, or AI site, grabman builds a clean project skeleton that already compiles with grab check, verifies every ecosystem layer version matches without conflicts, locks SHA-256 contract hashes so nothing drifts silently, checks Groxy AI Site DNA files for exact money math and HTML safety, and blocks insecure server defaults before they hit production.

1. Core Commands & Quick Start

grabman init --dir my-shop --profile ai-stack --name "Urban Roasters"
grabman init --dir my-shop --from-site-dna ./site-dna.json
grabman solve --dir my-shop --verify
grabman doctor --dir my-shop --strict
grabman dna validate ./site-dna.json --json
grabman dna diff ./old-dna.json ./new-dna.json
  • grabman init — Creates ready-to-compile workspaces (app, cms-stack, ai-stack, or hydrated directly via --from-site-dna). Never executes remote shell installers (zero curl | sh) and never overwrites existing files unless --force is supplied.
  • grabman solve [--verify] [--warn-incompatible] — Computes a deterministic 6-layer compatibility lockfile (grabman.lock). Supports non-blocking --warn-incompatible notices for intentional pins, while --verify fails closed on drift or unapproved v2.0.0 jumps.
  • grabman doctor [--strict] [--json] — Includes a dedicated Dependencies & Version Compatibility audit table (and JSON dependencies array) plus non-blocking warnings for overridden dependency pins, alongside live grab check, Site DNA exact decimals, template hygiene, and Compose security.
  • grabman dna validate / diff — Validates groxy-site-dna-v0.4.0 and v1.0.0 bundles, preserving exact base-10 ADR-025c prices and flagging style, token, price, or site-health deltas before deployment.
